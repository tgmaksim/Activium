# Активиум

Android-приложение для просмотра школьного расписания, домашних заданий, оценок и новостей школы.

Проект разрабатывается как основной клиент для школьной информационной системы и ориентирован на ежедневное использование.

---

## 📱 Основной функционал

### Расписание
- Просмотр расписания по дням недели
- Переключение дней жестами (влево / вправо)
- Мини-календарь для быстрого выбора дня

### Уроки
- Время урока
- Кабинет / место проведения
- Название предмета
- Домашнее задание (многострочный текст)
- Прикреплённые файлы
- Оценки за урок

### Уведомления
- Напоминания о внеурочных занятиях

### Настройки
- Включение / отключение уведомлений
- Выбор способа открытия файлов
- Выход из аккаунта
- Информация о приложении

### Обновления
- Экран обновления приложения
- Отображение списка изменений
- Возможность установки новой версии

---

## 🎨 Интерфейс

- Современный минималистичный дизайн
- Поддержка светлой и тёмной темы
- Material-анимации и ripple-эффекты
- Поддержка жестов и плавной прокрутки

---

## 🗂 Архитектура

- Экранная архитектура на Fragments
- Адаптеры для динамических списков
- Общие базовые модели API
- Поддержка расширения без изменения существующих экранов
- Чёткое разделение UI и логики
